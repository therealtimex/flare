Citation links a claim about a lead to the source it came from.

- Markup: `<a class="fl-cite" href="SOURCE_URL"><b>1</b>domain.com</a>`, placed right after the claim.
- You provide: the source URL, its number in the lead's source list, and the bare domain (no `https://`, no `www.`).
- Every sentence Flare writes about an account or person carries at least one citation. If there is no source, cut the sentence.
- Number citations in order of first use within a card; reuse the same number for the same source.
- Don't: hide sources behind a tooltip, or show a citation without a working link.
